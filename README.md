A tower defense game inspired by the Bloons TD series, but this one is themed around critters! This repo just has the code, the actual game can be found [here](https://arcade.makecode.com/S74547-15769-32510-22941).
 
Note: All the .ts files are where the game code is.

I plan on there being 12 towers, with 6 upgrades each. Each tower has 2 paths, and  once you get to the second upgrade, the other path is locked out, similar to BTD5 and 6.

How to play:
Right now, there's not really much gameplay, but the controls are simply left click to place a tower. I will keep working on this in the foreseeable future.
